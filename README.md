# AI Agents - Types of Environment

## Overview

This repository contains detailed notes on the **Types of Environment in Artificial Intelligence (AI)**. Understanding AI environments is essential for designing intelligent agents that can perceive, reason, and act effectively in different situations.

## Types of AI Environments

### 1. Fully Observable Environment
- The agent has complete information about the environment.
- No hidden states exist.
- Example: Chess, Tic-Tac-Toe.

### 2. Partially Observable Environment
- The agent has incomplete information.
- Decisions are made using memory or probability.
- Example: Self-driving cars, Poker.

### 3. Deterministic Environment
- Every action produces a predictable outcome.
- No randomness is involved.
- Example: Sudoku, Mathematical calculations.

### 4. Stochastic Environment
- Outcomes are uncertain and may vary.
- Probability is used for decision-making.
- Example: Weather forecasting, Stock market prediction.

### 5. Episodic Environment
- Each task is independent of previous tasks.
- No memory of past actions is required.
- Example: Image classification, Spam detection.

### 6. Sequential Environment
- Current actions affect future states.
- Planning and memory are important.
- Example: Chess, Robot navigation.

### 7. Static Environment
- The environment does not change while the agent is making a decision.
- Example: Crossword puzzles, Sudoku.

### 8. Dynamic Environment
- The environment changes continuously over time.
- Example: Traffic systems, Autonomous vehicles.

### 9. Discrete Environment
- The environment consists of a finite number of states and actions.
- Example: Tic-Tac-Toe, Chess.

### 10. Continuous Environment
- States and actions change continuously.
- Example: Robot arm control, Aircraft navigation.

### 11. Single-Agent Environment
- Only one intelligent agent interacts with the environment.
- Example: Vacuum Cleaner Agent.

### 12. Multi-Agent Environment
- Multiple intelligent agents cooperate or compete.
- Example: Robot soccer, Multi-player games.
